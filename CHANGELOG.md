# Changelog

## 1.0.1 — 2026-11-02

- Narrow the text-selection I-beam stem and its outline; keep the top/bottom bars, colors and hotspot unchanged.
- Narrow the center ornament to match the stem at 32/48/64 pixel sizes.

## 1.0.0 — 2026-11-02

- Initial public Windows package with double-click install, start, stop, status and uninstall entry points.
- Native EXE setup/control commands targeting .NET 2.0/3.5 APIs for Windows 7 SP1 compatibility; CLR 4 preferred on modern Windows. Win7 VM testing remains outstanding.
- Ivory glove click poses, matching loading animations and a gold-trimmed text I-beam.
- 32/48/64 pixel cursor assets and multi-resolution animated frames.
- Direct EXE login startup and a built-in watchdog process.
- Original registry-value backup and restore, including value kinds and absent values.
- Native Windows asset validation, PNG/RIFF integrity tests, release ZIP and SHA256 checksums.
- Chinese and English documentation, design provenance, and GitHub Actions release workflow.
