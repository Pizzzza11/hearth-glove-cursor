# Design provenance

Hearth Glove Cursor is an unofficial fan project by Pizzzza11.

The glove pose was inspired by publicly displayed legacy Hearthstone-style normal/click cursor references on RealWorld Graphics. The distributed glove artwork was redrawn with an image-generation tool using pose/readability references, rather than shipping the reference cursor files. The text cursor and spinner are drawn by the project's Python build script. Prompt history is retained in assets/DESIGN.md. AI-generated artwork may have different copyright treatment in different jurisdictions; the MIT grant covers only rights the contributors can grant.

No Blizzard logos, game binaries, extracted game assets, or original third-party reference cursor downloads are included in the repository or release package. Hearthstone and Blizzard names and any other third-party trademarks or rights remain with their respective holders and are not licensed by this project. This project is not endorsed by, sponsored by, or affiliated with Blizzard Entertainment.

Pillow is an optional development dependency, not bundled in the end-user ZIP. The runtime uses Windows APIs and the installed .NET Framework; no third-party runtime libraries are redistributed.
